# Cómo pedir otro vídeo

En el chat del nuevo proyecto se puede invocar:

```text
Usa $software-showcase-video para crear un comercial de este software con el
estilo APTUM que definimos: unos 45–50 segundos, textos en inglés, resultados
reales del proyecto, escenas que muestren los cambios y clip APTUM completo incluido en assets
al final. Conserva una portada visible desde el primer fotograma. Entrega MP4,
script reproducible, miniatura y hoja de contactos.
```

Para otra marca:

```text
Usa $software-showcase-video para este programa, manteniendo la composición
editorial y el ritmo. Adapta colores y fuentes a la guía de marca de
esta carpeta. Público: equipos de ingeniería. Idioma: español. Duración: 40 s.
```

Para revisar una versión existente:

```text
Usa $software-showcase-video y conserva esta versión como referencia. Mantén
estructura y textos; cambia solo la escena de comparación para que el visual
principal alterne los resultados reales. Revisa una preview antes del final.
```

También funciona para un recorrido explicativo más largo, una pieza de una
sola función o una animación de logo. Ajusta duración y número de capítulos al
encargo; el formato de 30–60 segundos no es una limitación del sistema.

## Qué se mantiene entre proyectos

Composición, familias tipográficas, márgenes, paleta APTUM cuando corresponda,
ritmo suave, portada inicial completa, cierre compacto, revisión visual y rigor
en cifras y resultados.

## Qué debe estudiarse de nuevo

Funciones implementadas, ejemplos, llamadas al núcleo, geometría, datos,
mediciones, público y beneficio del nuevo software. El skill no hereda pruebas
de eficacia, resultados físicos ni métricas de otro programa.
